# ObraClara

Este repositório contém a aplicação **Monitora TO** (focada em Palmas/TO), com:

- `monitora-to/backend`: API Node.js/TypeScript
- `monitora-to/web`: Front-end web (React + Vite)
- `monitora-to/mobile`: App mobile (React Native + Expo)

## Começar rápido

```bash
cd monitora-to
```

- Guia principal: `monitora-to/README.md`
- Setup em poucos minutos: `monitora-to/QUICKSTART.md`
- Entrada para navegação da documentação: `monitora-to/START_HERE.md`
